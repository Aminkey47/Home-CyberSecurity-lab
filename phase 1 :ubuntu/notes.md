# Phase 1: Ubuntu Linux Environment

## Overview
In this phase, I set up and explored an Ubuntu virtual machine as part of my cybersecurity learning journey. The goal was to understand basic Linux operations and build foundational skills needed for security testing and system administration.

## Setup
- Installed Ubuntu on a virtual machine (VMware)
- Configured basic system settings
- Ensured network connectivity between Kali Linux and Ubuntu

## Key Activities

### 1. Basic Linux Navigation
I learned how to navigate the file system using commands such as:
- `ls` – list files and directories
- `cd` – change directory
- `pwd` – show current directory
- `mkdir` – create directories

### 2. File Operations
- Created and managed files and folders
- Practiced moving and copying files using:
  - `cp`
  - `mv`
  - `rm`

### 3. System Information
- Checked system details using:
  - `uname -a`
  - `whoami`
  

### 4. Networking Preparation
- Verified IP address using `ip a`
- Prepared system for scanning from Kali Linux

## Outcome
I became comfortable using Linux terminal commands and navigating Ubuntu efficiently. This phase helped me understand the importance of Linux in cybersecurity environments.
